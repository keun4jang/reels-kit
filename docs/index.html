말하는 영상을 올릴 수 있는 세로 릴스로 만듭니다. 쉬는 구간과 다시 말한 문장을 잘라내고, 자막과 모션그래픽, 효과음을 넣습니다.

준비물

  • Claude Code (유료 요금제 Pro 이상. 처음이라면 아래 0단계부터)
  • 컴퓨터 (Windows 또는 Mac)와 인터넷
  • 말하는 영상 (휴대폰으로 세로로 찍은 영상이면 충분합니다)

0단계 Claude Code 처음 켜기

이미 Claude Code를 쓰고 있다면 건너뛰세요. 처음이라면 여기가 가장 중요합니다.

  1. Claude 앱 받아서 설치하기. 컴퓨터에서 claude.com/download 에 들어가 내 컴퓨터(Windows 또는 Mac)에 맞는 버튼을 누르고, 받은 파일을 실행합니다.
  2. 앱을 켜고 로그인하기. Claude Code는 유료 요금제(Pro 이상)에서만 쓸 수 있습니다. 무료 계정이면 요금제를 올리라는 안내가 나옵니다.
  3. 바탕화면에 "릴스" 폴더 만들기. 바탕화면 빈 곳에서 마우스 오른쪽 버튼 → 새로 만들기 → 폴더 → 이름을 릴스로 적고 엔터. (Mac은 오른쪽 버튼 → 새로운 폴더) 앞으로 찍은 영상은 전부 이 폴더에 넣습니다.
  4. Claude 앱에서 Code 누르기. 앱을 켜면 보통 대화하는 화면이 먼저 나옵니다. 앱 왼쪽 위에 있는 Code 를 누르면 Claude Code 화면으로 바뀝니다. 글자 없이 그림만 보이면 마우스를 올려 이름을 확인하세요.
  5. Local 고르기. 화면 가운데 글 쓰는 칸이 있습니다. 그 바로 아래 줄의 첫 번째 버튼을 눌러 Local 을 고릅니다. "내 컴퓨터에서 작업한다"는 뜻입니다.
  6. "릴스" 폴더 연결하기. 방금 누른 버튼 바로 옆의 폴더 버튼을 누르고 Open folder… 를 고릅니다. 파일 고르는 창이 뜨면 왼쪽에서 바탕화면(Desktop)을 누르고, 릴스 폴더를 한 번 눌러 고른 뒤 아래의 폴더 선택(Mac은 열기)을 누릅니다.
  7. 연결됐는지 확인하기. 폴더 버튼에 릴스라고 보이면 끝입니다. 이제 글 쓰는 칸에 말을 걸 수 있습니다. 한 번 연결해 두면 다음부터는 Code만 누르면 됩니다.

버튼 이름은 한글로 보일 수도 있습니다. 도중에 "허용할까요?" 같은 창이 뜨면 허용(Allow)을 누르세요. Claude가 내 컴퓨터에서 작업해도 되는지 묻는 것입니다.

1단계 설치 (처음 한 번만)

  1. 글 쓰는 칸에 아래 한 줄을 그대로 붙여넣고 엔터. 오른쪽의 "복사"를 누른 뒤, 글 쓰는 칸을 한 번 누르고 붙여넣기(Windows는 Ctrl+V, Mac은 ⌘+V) 하면 됩니다.

  2. "설치가 끝났습니다"가 나오면 완료. 앱을 한 번 껐다가 다시 켜 주세요. (바탕화면에 "릴스" 폴더가 없었다면 이때 자동으로 생깁니다)

2단계 릴스 만들기

  1. 휴대폰으로 찍은 영상을 컴퓨터로 옮기기. 편한 방법 하나만 쓰면 됩니다.
    • 아이폰 → Mac: 사진 앱에서 영상을 고르고 공유 → AirDrop → 내 Mac
    • 케이블: 휴대폰을 컴퓨터에 충전 케이블로 연결해 영상 파일을 꺼내기
    • 카카오톡: 나와의 채팅에 영상을 보내고 컴퓨터 카카오톡에서 내려받기. 보낼 때 화질을 원본으로 고르세요. 안 그러면 화질이 떨어집니다.
    • 구글 드라이브, iCloud 같은 곳에 올렸다가 컴퓨터에서 내려받기
  2. 그 영상을 바탕화면의 "릴스" 폴더에 넣기. 바탕화면의 릴스 폴더를 두 번 눌러 열고, 옮겨 온 영상 파일을 마우스로 끌어다 그 안에 놓습니다. 폴더 안에 영상이 보이면 된 것입니다. 영상이 여러 개면 가장 최근에 넣은 영상으로 작업합니다.
  3. Claude 앱을 켜고 왼쪽 위의 Code 누르기. 폴더 버튼에 릴스라고 보이는지 확인하세요. 다른 이름이 보이면 0단계의 6번을 다시 하면 됩니다.
  4. 글 쓰는 칸에 이렇게 쓰고 엔터.

    1분짜리 영상 기준으로 5~10분쯤 걸립니다. 기다리는 동안 "허용할까요?"가 나오면 허용을 누르세요.
  5. 완성본 찾기. 다 되면 바탕화면의 "릴스" 폴더 안에 "완성" 폴더가 생기고, 그 안에 릴스가 들어 있습니다. 이 파일을 휴대폰으로 옮겨 올리면 됩니다.

3단계 마음에 안 들면 말로 고치기

자막 더 크게효과음 줄여줘영문 자막 빼줘그래픽 없이 깔끔하게더 신나게이 부분은 빼줘

잘 나오게 찍는 법

  • 휴대폰을 세로로 들고 찍기
  • 문장 사이에 1초 쉬기 (자를 자리가 깔끔해집니다)
  • 틀리면 멈추지 말고 그 문장을 처음부터 다시 말하기 (마지막 것만 남깁니다)
  • 조용한 곳에서, 가능하면 마이크 쓰기 (자막이 정확해집니다)

눈이나 머리카락까지 뿌옇게 되지 않나요?
피부만 골라서 보정합니다. 눈, 눈썹, 입술, 머리카락, 배경은 그대로 둡니다.
무엇이 달라지나요?
잡티, 여드름 자국, 잔주름, 얼룩진 피부 톤이 줄어듭니다. "화장해줘"라고 하면 입술색, 블러셔, 눈 화장, 톤업이 더해집니다. 얼굴형을 바꾸지는 않습니다.
선글라스는 진짜처럼 보이나요?
아닙니다. 눈 위치를 따라가는 그림이라 스티커 느낌입니다. 안경을 쓴 채로 찍으면 안경테가 삐져나올 수 있습니다.
여러 사람이 나와도 되나요?
네. 화면에 보이는 얼굴을 모두 찾아 보정합니다.
돈이 더 드나요? 내 영상이 어디로 올라가나요?
키트는 무료이고 Claude Code 요금제의 사용량만 씁니다. 보정은 내 컴퓨터 안에서 하고, 확인용 장면 몇 장만 Claude가 읽습니다.
"피부 보정해줘"가 안 통해요.
Claude Code를 껐다 켠 뒤 다시 해 보세요. 그래도 안 되면 1단계 설치 문장을 한 번 더 붙여넣으세요.
