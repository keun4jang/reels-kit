Claude Code가 처음이라면앱 설치부터 폴더 여는 법까지
  1. Claude 앱 받기. 컴퓨터에서 claude.com/download 에 들어가 내 컴퓨터(Windows 또는 Mac)에 맞는 버튼을 누르고, 받은 파일을 실행합니다.
  2. 앱을 켜고 로그인하기. Claude Code는 유료 요금제(Pro 이상)에서만 쓸 수 있습니다. 무료 계정이면 요금제를 올리라는 안내가 나옵니다.
  3. 바탕화면에 "릴스" 폴더 만들기. 바탕화면 빈 곳에서 마우스 오른쪽 버튼 → 새로 만들기 → 폴더 → 이름을 릴스로 적고 엔터. (Mac은 오른쪽 버튼 → 새로운 폴더)
  4. 앱에서 그 폴더 열기. 앱 왼쪽 위의 Code 를 누릅니다. 글 쓰는 칸 아래에서 Local 을 고르고, 옆의 폴더 버튼 → Open folder… → 바탕화면의 릴스 폴더를 고릅니다. 버튼 이름은 한글로 보일 수도 있습니다.
  5. "허용할까요?" 창이 뜨면 허용. Claude가 내 컴퓨터에서 작업해도 되는지 묻는 것입니다.
잘 나오게 찍는 법찍을 때 네 가지만 지키면 결과가 달라집니다
  • 휴대폰을 세로로 들고, 얼굴이 화면에 크게 나오게 찍기
  • 문장 사이에 1초 쉬기 (자를 자리가 깔끔해집니다)
  • 틀리면 멈추지 말고 그 문장을 처음부터 다시 말하기 (마지막 것만 남깁니다)
  • 밝고 조용한 곳에서 찍기 (자막이 정확해지고 피부도 잘 나옵니다)

자주 묻는 질문

Claude Code를 한 번도 안 써 봤어요.

괜찮습니다. 괜찮습니다. 위 "사용법 PDF" 아래의 "Claude Code가 처음이라면"을 펼치면 앱 설치부터 폴더 여는 법까지 순서대로 나옵니다. 두 PDF의 0단계에도 같은 내용이 그림과 함께 있습니다.

돈이 드나요?

키트는 무료입니다. Claude Code를 쓰려면 Claude 유료 요금제가 필요하고, 그 요금제의 사용량 안에서 돌아갑니다.

내 영상이 어디로 올라가나요?

편집과 보정은 내 컴퓨터 안에서 합니다. 다만 받아쓴 글과 확인용 장면 몇 장은 Claude가 읽습니다.

결과가 매번 완벽한가요?

아닙니다. 자막 오타나 어색한 컷이 남을 수 있습니다. 올리기 전에 한 번 보고 "자막 더 크게", "이 부분 빼줘", "더 자연스럽게"처럼 말로 고치면 됩니다.

어떤 영상이 잘 되나요?

휴대폰으로 세로로 찍은, 한 사람이 말하는 영상이 가장 잘 됩니다. 밝은 곳에서 얼굴이 크게 나오면 보정과 화장도 잘 나옵니다.
