›릴스 만들어줘

이 키트로 만든 실제 릴스 화면입니다.

지금 휴대폰으로 보고 계신가요? 설치는 컴퓨터에서 해야 합니다. 주소를 복사해 두었다가 컴퓨터에서 열어 주세요.

준비물

  • Claude Code (유료 요금제 Pro 이상. 처음이라면 아래 0단계부터)
  • 컴퓨터 (Windows 또는 Mac)와 인터넷
  • 말하는 영상 (휴대폰으로 세로로 찍은 영상이면 충분합니다)

0단계 Claude Code 처음 켜기

이미 Claude Code를 쓰고 있다면 건너뛰세요.

  1. Claude 앱 받아서 설치하기. 컴퓨터에서 claude.com/download 에 들어가 내 컴퓨터(Windows 또는 Mac)에 맞는 버튼을 누르고, 받은 파일을 실행합니다.
  2. 앱을 켜고 로그인하기. Claude Code는 유료 요금제(Pro 이상)에서만 쓸 수 있습니다. 무료 계정이면 요금제를 올리라는 안내가 나옵니다.
  3. 바탕화면에 "릴스" 폴더 만들기. 바탕화면 빈 곳에서 마우스 오른쪽 버튼 → 새로 만들기 → 폴더 → 이름을 릴스로 적고 엔터. (Mac은 오른쪽 버튼 → 새로운 폴더)
  4. 앱에서 그 폴더 열기. 앱 왼쪽 위의 Code 를 누릅니다. 글 쓰는 칸 바로 아래 줄에서 첫 번째 버튼을 눌러 Local 을 고르고, 그 옆의 폴더 버튼 → Open folder… → 바탕화면의 릴스 폴더를 고릅니다. 버튼 이름은 한글로 보일 수도 있습니다.

도중에 "허용할까요?" 같은 창이 뜨면 허용(Allow)을 누르세요. Claude가 내 컴퓨터에서 작업해도 되는지 묻는 것입니다.

1단계 설치 (처음 한 번만)

  1. 글 쓰는 칸에 아래 한 줄을 그대로 붙여넣고 엔터.
    https://github.com/keun4jang/reels-kit 설치해줘
    Claude가 필요한 도구를 알아서 설치합니다. 5~10분쯤 걸립니다.
  2. "설치가 끝났습니다"가 나오면 완료. 앱을 한 번 껐다가 다시 켜 주세요. (바탕화면에 "릴스" 폴더가 없었다면 이때 자동으로 생깁니다)

2단계 릴스 만들기

  1. 바탕화면의 "릴스" 폴더에 영상 넣기. 찍은 영상을 마우스로 끌어다 놓으면 됩니다.
  2. Claude 앱을 켜고 Code 누르기. 폴더는 한 번 골라 두었으면 그대로입니다.
  3. 이렇게 쓰고 엔터.
    ›릴스 만들어줘
    1분짜리 영상 기준으로 5~10분쯤 걸립니다. 다 되면 "릴스" 폴더 안에 "완성" 폴더가 생기고, 그 안에 릴스가 들어 있습니다.

3단계 마음에 안 들면 말로 고치기

자막 더 크게효과음 줄여줘영문 자막 빼줘그래픽 없이 깔끔하게더 신나게이 부분은 빼줘

잘 나오게 찍는 법

  • 휴대폰을 세로로 들고 찍기
  • 문장 사이에 1초 쉬기 (자를 자리가 깔끔해집니다)
  • 틀리면 멈추지 말고 그 문장을 처음부터 다시 말하기 (마지막 것만 남깁니다)
  • 조용한 곳에서, 가능하면 마이크 쓰기 (자막이 정확해집니다)

자주 묻는 질문

돈이 더 드나요?
키트는 무료입니다. Claude Code 요금제의 사용량만 씁니다.
내 영상이 어디로 올라가나요?
편집은 내 컴퓨터 안에서 합니다. 다만 받아쓴 글과 확인용 장면 몇 장은 Claude가 읽습니다.
결과가 매번 완벽한가요?
아닙니다. 자막 오타나 어색한 컷이 남을 수 있습니다. 올리기 전에 한 번 보고, 고칠 곳을 말로 알려 주세요.
"릴스 만들어줘"가 안 통해요.
Claude Code를 껐다 켠 뒤 다시 해 보세요. 그래도 안 되면 1단계 설치 문장을 한 번 더 붙여넣으세요.
