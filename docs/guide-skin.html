0단계 Claude Code 처음 켜기

이미 Claude Code를 쓰고 있다면 이 쪽은 건너뛰세요.

1

Claude 앱 받아서 설치하기

›claude.com/download

인터넷 주소창에 위 주소를 치고, 내 컴퓨터(Windows 또는 Mac)에 맞는 버튼을 눌러 받은 파일을 실행하세요.

2

앱을 켜고 로그인하기

Claude Code는 유료 요금제(Pro 이상)에서만 쓸 수 있어요. 무료 계정이면 요금제를 올리라는 안내가 나옵니다.

3

바탕화면에 "릴스" 폴더 만들기

바탕화면 빈 곳에서 마우스 오른쪽 버튼 → 새로 만들기 → 폴더 → 이름을 릴스로 적고 엔터.
(Mac은 오른쪽 버튼 → 새로운 폴더)

이 폴더가 중요합니다. 앞으로 찍은 영상은 전부 바탕화면의 "릴스" 폴더에 넣습니다. 다음 장에서 Claude를 이 폴더에 연결합니다.

0단계 Claude를 폴더에 연결하기

처음 한 번만 하면 됩니다. 다음부터는 Code만 누르면 돼요.

4

앱 왼쪽 위의 Code 누르기

앱을 켜면 보통 대화하는 화면이 먼저 나옵니다. 왼쪽 위의 Code 를 누르면 Claude Code 화면으로 바뀝니다. 글자 없이 그림만 보이면 마우스를 올려 이름을 확인하세요.

5

Local 고르기

화면 가운데 글 쓰는 칸이 있습니다. 그 바로 아래 줄의 첫 번째 버튼을 눌러 Local 을 고릅니다. "내 컴퓨터에서 작업한다"는 뜻입니다.

6

"릴스" 폴더 연결하기

방금 누른 버튼 바로 옆의 폴더 버튼 → Open folder… 를 누릅니다. 파일 고르는 창이 뜨면 왼쪽에서 바탕화면(Desktop)을 누르고, 릴스 폴더를 한 번 눌러 고른 뒤 폴더 선택(Mac은 열기)을 누릅니다.

7

연결됐는지 확인하기

폴더 버튼에 릴스라고 보이면 끝입니다. 이제 글 쓰는 칸에 말을 걸 수 있어요. 버튼 이름은 한글로 보일 수도 있습니다.

도중에 "허용할까요?" 같은 창이 뜨면 허용(Allow)을 누르세요. Claude가 내 컴퓨터에서 작업해도 되는지 묻는 것입니다.

조절 · 팁

3단계 말로 조절하기

더 자연스럽게더 강하게입술은 코랄로핑크로 바꿔줘눈 화장은 빼줘선글라스 씌워줘릴스로도 만들어줘

영상의 크기, 길이, 소리는 그대로입니다. 원본 파일은 건드리지 않아요.

더 잘 나오게 하는 법

  • 밝은 곳에서 찍기 (창가나 조명 앞. 어두우면 얼룩이 더 보입니다)
  • 얼굴이 화면에 크게, 정면으로 나오게 찍기
  • 안경을 벗고, 머리카락이 눈과 입술을 가리지 않게 찍기
  • 처음에는 기본으로 보고, 부족하면 "더 강하게"

자주 묻는 질문

눈이나 머리카락까지 뿌옇게 되지 않나요?

피부만 골라서 보정합니다. 눈, 눈썹, 입술, 머리카락, 배경은 그대로 둡니다.

무엇이 달라지나요?

잡티, 여드름 자국, 잔주름, 얼룩진 피부 톤이 줄어듭니다. "화장해줘"라고 하면 입술색, 블러셔, 눈 화장, 톤업이 더해집니다. 얼굴형을 바꾸지는 않습니다.

여러 사람이 나와도 되나요?

네. 화면에 보이는 얼굴을 모두 찾아 보정합니다.

돈이 더 드나요? 내 영상이 어디로 올라가나요?

키트는 무료이고 Claude Code 요금제의 사용량만 씁니다. 보정은 내 컴퓨터 안에서 하고, 확인용 장면 몇 장만 Claude가 읽습니다.

"피부 보정해줘"가 안 통해요.

Claude Code를 껐다 켠 뒤 다시 해 보세요. 그래도 안 되면 1단계 설치 문장을 한 번 더 붙여넣으세요.
